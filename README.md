Este Projeto é sobre 1 pequeno simulador de caixa eletrônico, demonstrando algumas capacidades:
 - Botôes acessíveis diretamente por "mouse" no PC ou no "touchscreen" do celular;
 - 1 Página inicia já com o fluxo direcionado para campo de preenchimento de valor numérico;
 - Preenchimento de valor numérico dentro de restrições previstas (valores mínimo e máximo por exemplo);
 - Valor digitado em formato numérico aparece por extenso em letra vermelha na página seguinte;
 - Na tela com explicações sobre a senha, avisa que Cliente digitará teclas não numéricas do teclado (/ * - + .), de modo a evitar que "Hackers" e Curiosos vejam a senha digitada;
 - A senha, 5013 (pode-se informar nesse caso), é pedida ao Cliente, mas Cliente digitará teclas não numéricas ao invés dos números diretamente;

This project is about a small ATM simulator, demonstrating some features:
- Buttons accessible directly via the PC 'mouse' or the phone 'touchscreen';
- One page starts with the flow already directed to the numeric value input field;
- Filling in a numeric value within set limits (minimum and maximum values, for example);
- The entered value in numeric form appears spelled out in red letters on the next page;
- On the screen explaining the password, it warns that the client will type non-numeric keys on the keyboard (/ * - + .), to prevent 'hackers' and curious people from seeing the password input;
- The password, 5013 (can be given in this case), is requested from the client, but the client will type non-numeric keys instead of the numbers directly.
